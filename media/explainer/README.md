# Explainer film

A 72-second film made entirely in JavaScript. Every frame is a pure function of time (`src/film.mjs`), drawn by headless Chrome from `src/film.html`, and encoded by ffmpeg. All on-screen facts come from `src/data.json`, which `tools/build-data.mjs` builds from the Product Model and the run. The script is the `L1` to `L10` lines in `actualize/artifacts/motion-editorial/explainer-film.md`.

## Reproduce from source

```
bun media/explainer/tools/build-data.mjs                  # facts from the model and the run
bash -ic 'bun media/explainer/tools/tts-lines.mjs'         # narration, one line at a time (needs OPENROUTER_API_KEY in the environment)
bun media/explainer/tools/timeline.mjs --audio audio/lines.json   # line times, caption cues, WebVTT, transcript
bun media/explainer/tools/mix.mjs                          # room tone, placement, two-pass loudness to -16 LUFS
bun media/explainer/render.mjs --captions on  --out renders/silent-captioned.mp4
bun media/explainer/render.mjs --captions off --out renders/silent-clean.mp4
bun media/explainer/tools/finish.mjs                       # mux, tag BT.709, poster, probes
bun media/explainer/render.mjs --hash --stride 15          # determinism: run twice, digests must match
```

Narration model: `fish-audio/s2.1-pro-free:free` through OpenRouter, voice id `b347db033a6549378b48d00acb0d06cd`. The key is read from the environment only; `tools/tts.mjs` prints status, content type and size, never the key. If the free endpoint is unavailable the tool retries and then fails; it never substitutes another model.

## Files

| path | what |
|---|---|
| `src/` | the film (page, scenes, data, timeline) |
| `script/transcript.md`, `captions/explainer.en.vtt` | transcript and WebVTT captions |
| `audio/lines/`, `audio/narration.mp3` | the ten takes and the final mix (the mix WAV is regenerated by `tools/mix.mjs`) |
| `renders/explainer.mp4` | picture and sound, no burned captions (for the site, which carries a caption track) |
| `renders/explainer-captioned.mp4` | the same with captions burned in (for social and standalone) |
| `renders/poster.jpg` | poster frame |
| `storyboard/contact-sheet.png` | one frame at the start, middle and end of every scene |

## Known limits

- No human has listened to the narration (intelligibility, pronunciation of "Actualizer", tone). Measurements only.
- Sync is exact per line (each line is its own take) and proportional within a line for caption cuts.
- Commercial rights to the free model's voice are unconfirmed.
- hyperframes, bang-motion and anidoodle were not installed on the machine that made it, so a small purpose-built renderer was used with ffmpeg.
