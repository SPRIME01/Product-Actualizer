# Mote (working name): builder beta spec sheet

Mote is a desk companion robot kit in development.

The head assembly measures 92.4 x 71.0 x 80.5 mm in the current CAD [C22]. The neck is designed to pan +/-70 degrees and tilt -25 to +35 degrees against bracket stops [C22]; travel has not yet been measured on a built unit.

The host-to-neck command protocol is covered by automated tests [C1], and the neck firmware builds [C14]; it has not yet run on the current board revision.
