# Loam (working name)

**Stop guessing when to water.**

Loam is a soil probe. It reads how wet the soil is and turns it into a 0 to 100 number [C1][C2]. It sends each
reading to a server you point it at [C3], and it can email you when a reading is below an alert level [C4].

No app yet. Readings go to a server you run [C13][C3].
